**Welcome to your Base44 project** 
DataPulse is an AI-powered engineering observability platform. Here's what it does: 
�
� Core Problem It Solves 
Engineering teams are drowning in signals from too many tools — GitHub, Slack, Sentry, PagerDuty, 
Datadog, Jira, Linear — with no unified view. DataPulse aggregates all these signals, correlates them 
with AI, and surfaces what actually matters. 
Key Features 
�
� Data Sources Connect to GitHub, Slack, Sentry, Metrics, PagerDuty, Datadog, Jira, Linear, or any 
custom API. All records are normalized into a unified schema. 
�
� Incidents Automatically detect and correlate incidents across sources. AI performs root cause 
analysis and suggests next steps. Slack alerts for escalation. 
�
� Insights AI-generated findings: anomalies, trends, correlations, and recommendations surfaced 
from your live data streams. 
�
� Coral Query A natural-language + SQL interface to query across all your connected data sources 
in one place. 
�
� Analytics & Timeline Visual dashboards showing incident trends, error rates, and a chronological 
event timeline across all sources. 
�
� Executive Summary One-click AI-generated daily briefing for engineering leadership — system 
health, critical issues, and action items. 
�
� AI Agent A conversational assistant with full context of your data — ask questions, investigate 
issues, get recommendations. 
�
� Alerts & Webhooks Rule-based alerting (error spikes, keyword triggers, offline sources) with in
app, email, and webhook delivery. 
�
� Community & Profile Internal Q&A forum and user profile management. 
In Short 
DataPulse is a unified engineering intelligence layer — replacing the need to juggle 6+ dashboards 
by giving your team one place to monitor, investigate, and understand what's happening across their 
entire stack.

**Prerequisites:** 

1. Clone the repository using the project's Git URL 
2. Navigate to the project directory
3. Install dependencies: `npm install`
4. Create an `.env.local` file and set the right environment variables

```
VITE_BASE44_APP_ID=your_app_id
VITE_BASE44_APP_BASE_URL=your_backend_url

e.g.
VITE_BASE44_APP_ID=cbef744a8545c389ef439ea6
VITE_BASE44_APP_BASE_URL=https://my-to-do-list-81bfaad7.base44.app
```

Run the app: `npm run dev`

**Publish your changes**

Open [Base44.com](http://Base44.com) and click on Publish.
